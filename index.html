Guia de Publicação no GitHub Pages

  1. Crie uma conta gratuita no GitHub em github.com.
  2. Crie um novo repositório público com o nome, por exemplo, quiz-industria-40.
  3. Envie o arquivo index.html (ou os arquivos separados) para o repositório.
  4. No repositório, vá na aba Settings (Configurações) > Pages.
  5. Na seção Build and deployment, defina a branch como main ou master e pasta /(root).
  6. Clique em Save. Em instantes, o link público do seu quiz estará disponível!
